# speech для Android · beta-0.6

**Сурдоперевод и «Речь → текст» на телефоне Android**

Приложение **speech** помогает людям, которые не слышат или плохо слышат, общаться с теми, кто не знает жестового языка:

- **🤟 Жесты → текст и голос.** Человек показывает жесты в камеру — на экране сразу появляются слова крупным текстом, и телефон произносит их вслух.
- **🎙 Речь → текст.** Всё, что говорят вокруг, сразу появляется на экране крупным текстом. Реплика каждого человека — с новой строки.

> 🚧 **Бета-версия.** Приложение ещё проверяется на первых телефонах. Если что-то не работает — напишите в [Issues](../../issues) и приложите скриншот: модель телефона и версию Android.

> 🔒 **Изображение с камеры никуда не отправляется** — жесты распознаются прямо на телефоне. Речь распознаёт служба Google; если включить «Только на телефоне», звук тоже не уходит в интернет.

---

## Что нового в beta-0.6

- **🎯 Меньше ошибок в жестах.** Похожие слова (например, одна и та же кисть у подбородка и у груди) проверяются строже и больше не путаются. Поза засчитывается, только когда пальцы перестали двигаться, — переходы между жестами не превращаются в лишние слова.
- **🗣 Речь человека в 10 метрах** (Android 13 и новее). Кнопка 👂 усиливает тихий и далёкий голос до обычной громкости и убирает низкий гул. Если ваш телефон такой звук не поддерживает, приложение само вернётся к обычному микрофону.
- **🎧 Микрофон Bluetooth.** Дайте говорящему наушники с микрофоном — его будет слышно с любого расстояния, даже в шуме.
- **✋ Вторая рука не мешает.** Если одна рука лежит на столе или на коленях, жест второй рукой узнаётся как обычно.
- **🎨 Мягкий интерфейс.** Спокойные цвета, крупные кнопки, лёгкая вибрация, когда слово переведено.

Это первая версия в организации [SignSpeech](https://github.com/SignSpeech). Она продолжает beta-0.46 из [прежнего репозитория](https://github.com/Fen1x678/sign_language_interpretation_on_camera).

## Подойдёт ли мой телефон

| Что нужно | Зачем |
|---|---|
| **Android 8.0 или новее** | без этого приложение не установится |
| Камера | для жестов (подойдёт и фронтальная, и задняя) |
| Приложение **Google** | для «Речь → текст» — обычно уже стоит на телефоне |
| Android 13 или новее | только для усиления дальней речи (кнопка 👂) |
| Наушники Bluetooth с микрофоном | по желанию — если говорящий далеко или вокруг шумно |

Версию Android можно посмотреть так: **Настройки → О телефоне → Версия Android** (на некоторых телефонах — **Настройки → Система → О телефоне**).

## Установка

Готового файла для установки (APK) пока нет — приложение нужно один раз собрать на компьютере. Это бесплатно и занимает около получаса, большую часть времени компьютер сам скачивает нужные программы. Когда появится готовый APK, он будет в разделе [Releases](../../releases), и компьютер больше не понадобится.

### Что нужно

- компьютер с Windows, macOS или Linux и интернетом;
- программа [Android Studio](https://developer.android.com/studio) (бесплатная);
- кабель USB для телефона.

### 1. Скачайте приложение

На этой странице нажмите зелёную кнопку **Code → Download ZIP** и распакуйте архив.

Или через Git:

```bash
git clone https://github.com/SignSpeech/Android.git
```

### 2. Откройте в Android Studio

1. Запустите Android Studio → **Open** → выберите распакованную папку (в ней лежат файлы `settings.gradle.kts` и `gradlew`) → **OK**.
2. Подождите, пока внизу закончится **Gradle Sync**. В первый раз это несколько минут.
3. Если Android Studio предложит обновить что-нибудь (Gradle, плагин) — можно согласиться или отказаться, приложение соберётся в обоих случаях.

### 3. Подготовьте телефон

1. **Настройки → О телефоне** → 7 раз нажмите на **Номер сборки**. Появится надпись «Вы стали разработчиком».
2. **Настройки → Система → Для разработчиков** → включите **Отладка по USB**.
3. Подключите телефон кабелем к компьютеру. На телефоне нажмите **«Разрешить»**.

### 4. Установите

1. Вверху Android Studio выберите свой телефон в списке устройств.
2. Нажмите зелёную кнопку **▶ Run**.
3. Через минуту на телефоне откроется **speech**. Дальше компьютер не нужен — приложение остаётся на телефоне.

**Установить на другой телефон без кабеля:** в Android Studio **Build → Build App Bundle(s) / APK(s) → Build APK(s)** → в появившемся сообщении нажмите **locate** → отправьте файл `app-debug.apk` на телефон (в мессенджере или по почте), откройте его и разрешите установку из этого источника.

## Первый запуск

1. Приложение попросит доступ к **камере** — нажмите «Разрешить». Без камеры жесты не распознаются.
2. Доступ к **микрофону** приложение попросит, когда вы откроете «Речь → текст».
3. Записанные жесты хранятся только на вашем телефоне.

## Как пользоваться

### Научить приложение жестам

Приложение переводит те жесты, которые вы ему показали. Каждое слово нужно записать один раз:

1. Внизу нажмите **«＋ Словарь»**.
2. Введите слово, например «привет».
3. Выберите тип: **«С движением»** (жест с движением руки) или **«Поза»** (рука неподвижна).
4. Нажмите **«Записать жест»**. После обратного отсчёта покажите жест. Запись пройдёт 3 раза: прямо, чуть левее и чуть правее — так жест будет узнаваться и под углом.

Каждое слово лучше записать 2–3 раза, лучше разными людьми: так оно будет понятно у всех.

### Перевод жестов

1. Показывайте жесты в камеру. Слово появится внизу крупным текстом и прозвучит голосом. При каждом переведённом слове телефон слегка вибрирует.
2. Опустите руки на 2 секунды — фраза закончится и уйдёт в историю.
3. Кнопки под фразой: **⌫** — стереть последнее слово, **✓ Готово** — закончить фразу, **▶** — произнести ещё раз, **🔊** — включить или выключить голос, 🗑 — очистить.

**Какую камеру выбрать** (кнопка 🔄 вверху):
- **задняя** — наведите телефон на собеседника, перевод появится на экране и прозвучит голосом;
- **фронтальная** — человек сам видит, правильно ли переведены его жесты.

### Речь → текст

1. Нажмите **«🎤 Речь → текст»**.
2. Положите телефон между собеседниками. Текст появляется сразу, а фраза, которая ещё звучит, подсвечена янтарным.
3. Кнопки внизу:

| Кнопка | Что делает |
|---|---|
| 🗑 | очистить текст |
| 👂 | дальняя речь: усиление тихого и далёкого голоса (Android 13+, включено сразу) |
| 🎤 / ■ | слушать / пауза |
| **Aa** | крупнее или мельче текст |
| 🎧 | микрофон Bluetooth-наушников |

4. Кнопка **⋯** вверху: **«Мои слова»** (имена и редкие слова — они будут распознаваться точнее), **«Новая строка после паузы»**, **«Только на телефоне»** (без интернета, Android 12+), **«Без звукового сигнала»**.
5. Чтобы перечитать сказанное, листайте вверх. Кнопка **«↓ К новым»** вернёт к живому тексту.

### Человек далеко (до 10 метров)

1. Проверьте, что кнопка 👂 включена (бирюзовая).
2. Положите телефон **низом к говорящему** — микрофон находится внизу телефона. Ничто не должно его закрывать.
3. Полоска громкости над кнопками стала мятной — значит, телефон слышит голос.
4. В тихом помещении голос с 10 метров распознаётся. На улице, в транспорте или при музыке дайте говорящему **наушники Bluetooth с микрофоном** и нажмите 🎧.

### Подсветка

Кнопка 🔦 вверху: **Авто** — свет включается сам, когда темно; **Всегда вкл.**; **Выключена**. У задней камеры светит фонарик, у фронтальной — экран (яркая белая рамка).

## Советы для точного распознавания

- Держите руки в 30–80 см от камеры, чтобы кисти целиком были в кадре.
- Пусть в кадре будут видны плечи: тогда одна и та же форма кисти у подбородка, у груди и у плеча — разные слова.
- Показывайте жест так же, как при записи.
- Нужен свет. Яркое окно за спиной мешает.
- Вторую руку, если она не участвует в жесте, держите опущенной (на экране она станет серой).
- Подсказка «Похоже на «слово» — N%» показывает, насколько жест похож на записанный. Если процент высокий, а слово не засчитывается — сдвиньте «Чувствительность» (в «Словаре») вправо.

## Частые проблемы

| Проблема | Что сделать |
|---|---|
| Чёрный экран вместо камеры | **Настройки → Приложения → speech → Разрешения → Камера** → разрешить. |
| Жест не распознаётся | Запишите слово ещё 1–2 раза (лучше другим человеком), добавьте света или сдвиньте «Чувствительность» вправо. |
| Появляются лишние слова | Сдвиньте «Чувствительность» влево. |
| Жест одной рукой не узнаётся, когда видна вторая рука | Опустите вторую руку на стол или колени. Если жест записывали, когда вторая рука была видна, перезапишите его. |
| После обновления какое-то слово узнаётся хуже | Похожие слова теперь проверяются строже. Запишите слово ещё 1–2 раза или сдвиньте «Чувствительность» чуть вправо. |
| «Нет службы распознавания речи» | Установите или обновите приложение **Google** в Play Маркете. |
| «Русский язык для распознавания недоступен» | **Настройки → Система → Языки → Распознавание речи** — загрузите русский язык, или выключите «Только на телефоне». |
| Человек далеко, текста нет | Включите 👂, положите телефон низом к говорящему. В шуме — наушники Bluetooth у говорящего и кнопка 🎧. |
| «Усиление дальней речи на этом телефоне не работает» | Служба распознавания вашего телефона его не поддерживает — приложение слушает обычным микрофоном. Обновите приложение **Google** или используйте наушники Bluetooth. |
| «Наушники Bluetooth не подключены» | Подключите наушники в настройках Bluetooth и снова нажмите 🎧. |
| Слышен сигнал при каждой фразе | Кнопка **⋯ → «Без звукового сигнала»**. На некоторых телефонах этот сигнал приглушить нельзя. |
| Android Studio: «Could not find …» | Проверьте интернет и нажмите **File → Sync Project with Gradle Files**. |
| Android Studio: телефона нет в списке | Включите «Отладку по USB», переподключите кабель и нажмите «Разрешить» на телефоне. |

Не нашли свою проблему? Напишите в [Issues](../../issues): что делали, что произошло, модель телефона и версию Android.

## Что пока не умеет

- Приложение не знает жестовый язык заранее — оно переводит только жесты, которые вы записали.
- Мимика не учитывается.
- Словарь хранится на одном телефоне, перенести его на другой пока нельзя.
- Перевести телефонный звонок нельзя: Android не даёт приложениям звук звонка.
- «Речь → текст» не различает людей по голосу: реплики разделяются по паузам.

## Для разработчиков

**Технологии:** Kotlin, Jetpack Compose, CameraX, MediaPipe (21 точка кисти и плечи), системное распознавание речи Android.

```
app/src/main/java/com/fen1x/speech/
├── MainActivity.kt, GestureViewModel.kt — точка входа и логика экрана
├── camera/   — камера (CameraX) и MediaPipe
├── core/     — алгоритмы на чистом Kotlin: признаки позы, k-NN, DTW, словарь,
│               защита от ошибок, исправление речи, усиление дальней речи
├── speech/   — «Речь → текст» и запись микрофона с усилением
└── ui/       — экраны (Jetpack Compose) и оформление
app/src/test/ — тесты алгоритмов
app/src/main/assets/ — модели MediaPipe
```

- **Тесты:** `./gradlew test` или в Android Studio правой кнопкой по `app/src/test` → **Run Tests**. Алгоритмы проверены 53 тестами.
- **Как устроено распознавание:** камера → MediaPipe (точки рук и плечи) → сглаживание → признаки позы и движения → k-NN / DTW → слово. Подробное описание алгоритмов — в [README версии для iPhone](https://github.com/Fen1x678/sign_language_interpretation_on_camera/blob/beta-0.46/GestureControl/README.md): алгоритмы у Android и iPhone одинаковые.
